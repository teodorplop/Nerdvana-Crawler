# Nerdvana-Crawler

Extracts scores of users from platforms like:
* [Infoarena](https://infoarena.ro/)
* [Nerdarena](https://www.nerdarena.ro/)
* [Kilonova](https://kilonova.ro/)

Populates Google Spreadsheet with the scores. Example:
